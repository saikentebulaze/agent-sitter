## 3. Core intent to preserve

V6.3 must preserve exactly two top-level goals:

1. **Context Capability**
2. **Human Decision Authority**

LOW Fast Path remains a constraint, not another top-level goal.

The complexity rule is:

> **Preserve Information. Preserve Guarantees. Compress Ceremony.**

The cost rule is:

> **Minimum Sufficient Capability: use the least expensive capability that can reliably satisfy the same quality and assurance requirement, and stop when the requirement is satisfied.**

Cheap subagents are a mechanism, not the objective.

## 7. Implementation economics

Apply this ladder whenever Sitter itself chooses how to obtain context or proof:

```text
deterministic
    ↓ insufficient
cheap narrow specialist
    ↓ insufficient
mid-tier specialist
    ↓ insufficient
strong model
    ↓ material unresolved fork
human authority
```

Specific rules:

- deterministic facts do not need models;
- use cheap models to retrieve/filter context when they can reliably do so;
- stronger models should consume already-filtered context rather than repeat broad scans;
- reasoning effort should be role/problem appropriate;
- default to one relevant Scout;
- parallelize only independent unknown surfaces;
- reuse valid delegation evidence within the same Task when authority/surface/question remain current;
- child-to-parent output should be dense evidence rather than long prose;
- once the requirement is satisfied, stop.

Governance Core remains model-name neutral. Codex/Claude Providers map provider-neutral role needs to their current native model/subagent capabilities.

Actual runtime model/permission behavior must still be attested; configuration files alone are not proof.

## 8. Compatibility strategy

V6.3 should be incremental.

Existing V6.2 active work must continue without a mandatory migration ceremony.

Rules:

- existing Task/Change references continue to work;
- Review Protocol 2 historical evidence remains valid/replayable;
- old low-level CLI remains temporarily available as recovery API;
- old `completion.*` may remain serialized compatibility projections while new logic stops treating them as authority;
- absence of Task-output metadata keeps conservative V6.2 production behavior;
- telemetry is optional and never correctness authority;
- ambiguous behavior falls back to the stricter old behavior.
