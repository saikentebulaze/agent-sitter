# 知识更新策略

## 权威范围

`knowledge/` 保存人工审核的稳定架构认知。`knowledge/generated/` 仅为非权威导航。

## 触发条件

模块职责、业务链、数据流、状态所有权、接口契约、设计决策、当前/目标/过渡状态、legacy 模式、重大验收策略发生变化。

普通局部 bug 和实现细节通常不更新。

## 状态

- current：当前推荐事实；
- target：已批准目标设计；
- transitional：显式过渡；
- legacy：当前存在但不得扩散；
- disputed：存在未解决冲突。

## 审核

Agent 只生成候选更新。设计决策、目标状态和 legacy 判断必须人工审核。
