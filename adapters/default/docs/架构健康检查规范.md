# Sitter Architecture Health Check

## Scope

只读检查指定模块、业务链或一组近期 Change，不做全仓库无目的扫描。

## 固定检查

- 同一状态是否存在多个权威来源；
- 同一职责是否有平行实现；
- Creator、Analysis、Kernel、Mesh、Result、Writer 边界是否漂移；
- Adapter、配置、开关和兼容层是否叠加；
- helper 和抽象是否增加而未降低复杂度；
- 防御、日志、异常和 fallback 是否扩散；
- 测试是否绑定内部实现或测试 seam 过多；
- legacy 模式是否在新代码中复制；
- 知识与当前代码是否失配。

## 输出

生成 `.agent-work/<task-id>/architecture-health.md`：

- PASS/WARN/BLOCK 仅表示健康调查结论，不授权修改；
- 每个候选债务包含事实、影响、证据、置信度和建议优先级；
- 区分已有债务与本次 Change 新增熵；
- 输出 `knowledge/debt/` 候选，不直接写入权威条目；
- 不提供大规模重构补丁。
