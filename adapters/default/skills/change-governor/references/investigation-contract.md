# 调查契约

调查目标不是“读很多代码”，而是形成任务相关的完整业务闭环。

## 必须覆盖

1. 纵向业务链：输入、转换、创建、初始化、更新、计算/组装、结果恢复、输出。
2. 横向框架参照：相似实现、现有惯例、可复用机制、历史模式。
3. 语义所有权：创建、持有、更新、读取、提交、失效和唯一真相来源。
4. 测试证据：现有测试证明和未证明什么。
5. 历史与知识：设计决策、临时状态、技术债和特殊业务要求。

## 输出纪律

- 固定结构、压缩结论、精确索引、未确认项；
- 区分 FACT、INFERENCE、PROPOSAL；
- 不复述函数，不大段复制代码；
- “未发现”必须说明搜索范围；
- 报告过长时判断任务是否应拆分。
